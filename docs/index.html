THE BUSINESS

IF IT PLAYS, IT LEADS

Playback joins at the guide’s current time. A show that started at 4:00 starts twenty minutes in at 4:20. Start over on the HUD plays from 0:00. Video plays in the page — H.264 MP4 over HTTP Range, everything else packaged as MPEG-DASH. Optional mpv on the server.

OVERNIGHT SHIFT

THE GRID NEVER STOPS

Real durations from ffprobe. A rolling window from now − 6 hours through now + 18. Sequential loops a playlist; random shuffles the library. Adjacent blocks abut. There are no commercial gaps unless you put commercials in the folder.

PUBLIC ACCESS

YOUR FOLDER IS A CHANNEL

Classic channel folders still work. A Jellyfin parent with Movies/ and Shows/ is detected and mixed onto genre cable channels with invented names — Nightfall, Thunderbolt, Chuckle, Starline, Toonbox, Prime, Local 8. No account. No cloud. Offline-first on Linux.

SYS TECHNICAL · WHAT’S ON THE WIRE
  • 07 CRT / VHS ntsc-rs look. NTSC composite or tape. HUD checkbox. CSS filter in-page so NFS stays fast.
  • 12 IR REMOTE Arrows, OK, Esc, CH+/−, digits with cable-style timeout. Optional evdev grab.
  • 18 LAN WATCH Bind 0.0.0.0. dash.js is vendored. A laptop on the same Wi-Fi opens the guide and watches.
  • 24 ART & NFO Local posters first. Optional keyless TVMaze / iTunes lookups, cached.
  • 31 ORGANIZE Loose filenames parsed, looked up, moved into a Jellyfin layout. Existing files never overwritten.
  • 36 HEADED / HEADLESS One FastAPI process. Opens a browser, or serves the same page on a box with no display.

They Live hid the ads in the ads. Nightcrawler sold the footage back to the same city that produced it. LocalCable is the opposite trick: the guide is the product, and the product is your own shelves.

INSTALL · TONIGHT

Python 3.11+ · uv or pip · ffmpeg / ffprobe · optional mpv

cd LocalCable
uv sync --extra dev
uv run localcable --media-root ~/Videos

Then open http://127.0.0.1:8787/ — or bind 0.0.0.0 and watch from another computer on the LAN.

README

As seen after sign-off. Not available in stores. Rewind is a courtesy.

Everything runs offline on Linux except optional keyless artwork lookups. One process serves the guide, the streams, and the schedule. Headed mode opens a browser. Headless mode is the same page on a box in the closet.
